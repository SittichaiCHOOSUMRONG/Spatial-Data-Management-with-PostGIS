#Spatial Data Management with PostGIS

📖 Spatial Data Management with PostGIS เป็นหนังสือที่จัดทำขึ้นเพื่อใช้ประกอบการเรียนการสอนด้านฐานข้อมูลเชิงพื้นที่ (Spatial Database) และภูมิสารสนเทศ (Geoinformatics) โดยเน้นการใช้งาน PostgreSQL/PostGIS ซึ่งเป็นระบบฐานข้อมูลเชิงพื้นที่แบบโอเพนซอร์สที่ได้รับความนิยมทั่วโลก

หนังสือเล่มนี้ครอบคลุมเนื้อหาตั้งแต่พื้นฐานไปจนถึงการประยุกต์ใช้งานจริง ได้แก่

- Introduction to Spatial Database Systems
- PostgreSQL and PostGIS Installation
- Spatial Data Types and Geometry
- Spatial SQL Queries
- Spatial Analysis and Geoprocessing
- Spatial Indexing and Performance Optimization
- Integration with QGIS
- Web GIS Development
- API-based Spatial Data Services
- Real-world Geospatial Applications

- ✅ ตัวอย่างฐานข้อมูล (Sample Databases)

- ✅ ตัวอย่างการพัฒนา Web GIS และ API
- ✅ แบบฝึกหัดและกรณีศึกษาสำหรับฝึกปฏิบัติ

หนังสือเล่มนี้เหมาะสำหรับ

- 👨‍🏫 อาจารย์และนักวิจัยด้านภูมิสารสนเทศ
- 🏛️ หน่วยงานภาครัฐและเอกชนที่ทำงานด้านข้อมูลเชิงพื้นที่
- 💻 นักพัฒนาระบบ GIS และ Web GIS
- 🌏 ผู้ที่สนใจเรียนรู้ Spatial Database ด้วยตนเอง

Repository Purpose

This repository provides datasets, SQL scripts, source code examples, and learning materials accompanying the book "Spatial Data Management with PostGIS", enabling readers to practice and develop practical geospatial applications using open-source technologies.
